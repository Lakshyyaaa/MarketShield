17) Software Testing Procedures - The system auditor should check whether the stock broker has complied with the guidelines and instructions of SEBI / stock [page 318] Page 318 of 348 exchanges with regard to testing of software and new patches, including the following: a. Test Procedure Review – The system auditor should evaluate whether the procedures for system and software testing were proper and adequate. b. Documentation – The system auditor should verify whether the documentation related to testing procedures, test data, and resulting output were adequate and follow the organization's standards. c. Test Cases – The system auditor should review the internal test cases and comment upon the adequacy of the same with respect to the requirements of the Stock Exchange and SEBI.
